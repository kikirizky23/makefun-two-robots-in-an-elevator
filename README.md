One awkward line of small talk from one robot to another in an elevator: **"Do not worry. I calculated the odds of us getting stuck in here: 0.03%. I also calculated the odds of this conversation getting stuck: 100%."** The gag is a reassurance that backfires — the robot soothes the fear of getting stuck in the lift with a precise probability, then applies the same cold arithmetic to the conversation itself and admits, with total certainty, that the chat is already doomed. The program writes this one line to `/output/entry.txt` and nothing else: one line, 140 characters, no trailing newline.

## Run it

```sh
node main.ts
```

It makes the output folder when it is missing, writes `/output/entry.txt` as UTF-8 (one line, no trailing newline), then reads the file back to make sure it holds exactly the line above.
